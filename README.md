# PLOTWEAVER 🧵

**TRPG 시나리오 집필 및 서사 설계 도구 · v0.1 첫 작동 버전**

아이디어에서 사건, 장면, 진상, 최종 원고까지 이어지는 **로컬 우선** 집필 환경입니다. 프로그램은 질문을 제공하지만, 이야기의 내용과 방향은 창작자가 결정합니다.

## 실행 및 배포
- 개발: Node.js 20 이상 설치 → npm install → npm run dev
- 배포용 빌드: npm run build
- GitHub Pages 예정 URL: https://sea-anemone17.github.io/PLOTWEAVER/
- 저장소 Settings → Pages → Build and deployment → Source: GitHub Actions 선택
- 배포 후 브라우저의 '앱 설치' 또는 '홈 화면에 추가' 사용 가능 (플랫폼 지원 시)

## 구현된 기능
- 프로젝트 시작 마법사(현재 집필 상태, 자유 구상, 어려움, 작업 방식)
- 프로젝트 생성·복제·삭제, JSON 전체 백업·복원(복원 시 별도 프로젝트 생성)
- 아이디어 카드·검색·분류, 아이디어 원본을 유지한 장면 연결
- 24개 질문의 서사 워크숍(사건 중심형/미스터리 역설계형)
- 실제 사건 연대기 및 플레이 장면 관리, 복수 후속 장면, 단계별 카드 보드
- 의문과 가설, 가설 채택 및 해결 상태
- 세계관·NPC·HO·진상·규칙·엔딩 조건과 단서 관리
- Tiptap 연속 원고 편집(제목 1–6, 목록, 인용, 링크, 이미지, 표 및 셀 병합, 목차)
- 기본 DOCX 다운로드, 선택적 GM 자료 포함
- Dexie + IndexedDB 저장, GitHub Pages용 PWA, 반응형 화면

## 주의 및 현재 한계
1. 브라우저 데이터 삭제 또는 기기 변경 시 IndexedDB가 사라질 수 있으므로 정기적으로 JSON을 백업하세요. 원고는 GitHub에 자동 업로드되지 않습니다.
2. DOCX 출력은 문단, 제목, 기본 목록과 표 중심입니다. 이미지·정교한 표 스타일·복잡한 서식은 정확히 보존되지 않을 수 있습니다. Google Docs 가져오기도 확인이 필요합니다.
3. Asta Sans는 라이선스와 웹 임베딩 조건 확인 전까지 포함하지 않았습니다. 현재 Noto Sans KR과 시스템 글꼴을 사용합니다.
4. 원고 단락과 설계 카드의 직접 연결, 시각적 노드 관계도, 자동 모순 검사는 미구현입니다.
5. AI 자동 서사 작성, 회원가입, 클라우드 동기화, 공동 편집은 제공하지 않습니다.
6. PWA 아이콘은 SVG 기반이며 플랫폼별 실제 설치·오프라인 동작은 기기에서 추가 검증이 필요합니다.
7. 기술 초안의 Tailwind 대신 의존성을 줄인 일반 CSS를 사용했습니다.
