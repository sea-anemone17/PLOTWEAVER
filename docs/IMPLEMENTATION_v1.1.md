## 범위 주의

기존 v0.1 연속 원고와 신규 장면별 원고를 모두 유지합니다. 이번 PR에서 PlotEdge 데이터 모델과 전체·미니 관계도, 선택적 구조화 블록, 전역 아이디어 정원, 지식 보관함, 논증형 주제의식의 기본 기능까지 구현했습니다. 아직 고급 교차 관계 시각화·개정 비교·실제 페이지 단위 DOCX 미리보기·Drive 동기화는 별도 단계입니다.

전역 연구 자료는 연구 보관함 JSON으로 별도 백업하거나, **전체 작업 공간 ZIP**에 모든 프로젝트와 함께 넣어 보존할 수 있습니다. 각 프로젝트 ZIP에는 실제 파일 핸드아웃과 프로젝트 원고를 포함하며, 백업 파일의 각 첨부파일은 SHA-256으로 검증됩니다. 프로젝트에 고정된 주제의식의 불변 사본은 단독 ZIP에서도 보존되고, 전체 작업 공간 ZIP을 복원하면 가져온 전역 개정본 ID까지 재연결합니다.

기존 프로젝트 JSON 백업 형식(v1)은 유지하되, 첨부파일이 있을 때 JSON 단독 내보내기는 안전을 위해 차단합니다. 파일 원본까지 완전 복원하려면 ZIP 백업을 사용해야 합니다. 인라인 이미지 데이터 URI는 기존 원고 데이터에 남아 있으나, DOCX에서는 별도 이미지 처리 개선이 필요합니다. 프로젝트·전역 자료 모두 ZIP 복원 시 기존 원본을 덮어쓰지 않습니다.

TRPG 블록은 자유 서술과 독립적인 구조화 필드를 모두 저장합니다. 분기 블록은 공통 PlotEdge의 ID를 참조할 수 있으므로 연결 삭제 시 원고는 유지되며 연결 누락을 확인할 수 있습니다. 다만 판정 결과 필드의 고급 템플릿·중복 검토 기능은 후속 개발 범위입니다.

## 검증 기준

1. 이전 v0.1 프로젝트를 정상적으로 열고 저장할 수 있어야 합니다.
2. 삭제한 프로젝트를 휴지통에서 복원하면 원고와 관계 데이터가 남아 있어야 합니다.
3. 손상되거나 지원하지 않는 JSON 백업은 기존 프로젝트를 변경하지 않고 거절해야 합니다.
4. 원고를 연속 입력할 때 마지막 입력 시점의 문서 내용이 IndexedDB에 저장되어야 합니다.
5. TRPG 블록 작성 후 앱 재시작 및 DOCX 출력에도 본문과 블록 종류가 유지되어야 합니다.
6. 기존 v0.1 장면 후속 관계가 v4 업그레이드 후 PlotEdge로 보존되어야 합니다.
7. 관계도에서 순환 경로·같은 두 장면 사이의 복수 관계·수동 위치 배치가 가능해야 합니다.
8. 프로젝트 복원 후 분기 블록 안의 PlotEdge 참조가 새로운 관계 ID로 연결되어야 합니다.
9. 플레이어용 DOCX에서 GM 전용 블록과 해당 구조화 정보가 제외되어야 합니다.

> 자동 빌드 통과는 위 브라우저 실사용 테스트의 대체가 아닙니다.

## 전역 연구 기능 수용 기준 (추가)

10. 아이디어의 메모·계층형 보기·마인드맵에서 동일한 제목과 메모가 표시되어야 합니다.
11. 아이디어를 자신의 하위 노드로 이동하는 순환 관계는 거절되어야 합니다.
12. 이름 붙인 주제의식 개정본은 이후 초안을 수정해도 변경되지 않아야 합니다.
13. 프로젝트에 고정한 개정본의 사본은 전역 자료 없이도 프로젝트 백업에서 복원되어야 합니다.
14. 연구 보관함 백업을 복원하면 부모 관계, 교차 참조, [[내부 링크]] ID가 복원된 자료를 가리켜야 합니다.
15. 연구 편집 중 미저장 입력이 존재한다면 개정본 생성·백업 전에 저장 완료 여부를 확인해야 합니다.

## 출력·파일 백업 수용 기준 (추가)

16. PDF·이미지 파일 핸드아웃을 등록한 프로젝트는 ZIP 복원 후 파일 원본 바이트가 동일해야 합니다.
17. 누락되거나 변경된 첨부파일은 검증 시 거절되고, 원래 프로젝트 데이터는 유지되어야 합니다.
18. 휴지통 복원과 복제 작업에서도 저장된 파일 핸드아웃이 보존되어야 합니다.
19. 전체 작업 공간 ZIP은 프로젝트와 전역 연구 자료 및 개정본 연결을 함께 복원해야 합니다.
20. 배포용 DOCX에서 GM 전용 블록·구조화 필드·핸드아웃이 실제 파일에 포함되지 않아야 합니다.
21. 출력 프로필의 포함 범위에 따라 기존 연속 원고·장면 원고·핸드아웃 출력 여부가 달라져야 합니다.
22. ZIP 백업은 현재 브라우저 저장소와 독립된 위치에 사용자가 보관해야 장기 보존 효과가 있습니다.
